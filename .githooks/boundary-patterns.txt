# Sibling boundary patterns
#
# Format: [owner] <regex> — [owner] prefix marks the sibling that owns the
# pattern. Own-repo patterns are filtered out by the hook (a sibling-a repo
# doesn't trigger on [sibling-a] patterns; a sibling-b repo does).
#
# Update policy: edit this file directly via PR. If a match is a false
# positive, refine the regex instead of disabling the file.
#
# The sentinel below keeps the hook's grep pipeline well-formed even when
# no real patterns are configured. Replace it with your own patterns as
# needed.

[sibling-example] \b__LANEKEEP_BOUNDARY_PATTERN_SENTINEL__\b
